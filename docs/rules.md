# 試験ルール(センス)
## 1ターンの流れ
### デフォルト
- 1ターンに3枚引く。  
- 1枚カードを選択して使用する。  
- 休むを選択すると体力を2回復する  
- コストの数値を　元気から引き、負の数になった場合、絶対値の大きさ分を体力にから消費する。  
  - 体力がマイナスになる場合、カードを灰色にして使用できないようにする。  
  - 赤色のコストは元気を無視して消費する。  

### 処理の順番
1. ターン開始  
   - ターン数つきの効果(好調・集中以外のバフなど)のターン数を1減らす。  
   - ただし、そのターンにプレイヤーが操作する前に付いた効果は減らさない。  
2. 山札からスキルカードを3枚引く。  
3. ターン開始後の効果を処理する。  
   - 「次のターン」「Nターン後」で予約された効果をここで発動する。  
4. プレイヤーの行動  
   1. カードの使用条件を確認する。  
   2. コストを払う。  
   3. 「スキルカード使用時」の効果を処理する。  
   4. カードの効果を、上の行から順番に処理する。  
   5. 「スキルカード使用後」の効果を処理する。  
   6. スキルカード使用数が残っていれば、4に戻る。  
   - 休むを選んだ場合も、この段階で処理する。  
5. ターン終了  
   - ターン数つきの効果のターン数を1減らす。  
   - ターンが残っていれば1に戻る。  

### カードの移動
- 使ったカードは捨て札に移動する。  
- レッスン中1回のカードは除外に移動する。(山札に戻らない)  
- 山札がなくなったら、捨て札を新しい山札にする。(順番はランダム)  

# 計算式
## 体力消費
- 最終体力消費量 = カードなどの体力消費量 × 体力消費倍率 + 体力消費追加 - 体力消費削減  
- 計算したあと、小数点以下を切り上げる。  

### 体力消費倍率
| 消費体力減少 | 消費体力増加 | 倍率 |
|---|---|---|
| あり | あり | 1 |
| あり | なし | 0.5 |
| なし | あり | 2 |
| なし | なし | 1 |

- 体力回復には、この倍率はかからない。  

体力が減少する場合
# 緑消費
- 最終元気 = 現在の元気 - 最終体力消費量 (負の場合,下の式に移行)

- 体力 = 現在の体力 + 最終元気  
# 赤消費
- 体力 = 現在の体力 - 最終体力消費量

## パラメータ上昇量
- 最終パラメータ上昇量 = カードのパラメータ値(最終) × 好調・絶好調倍率 × (1 + パラメータ上昇量増加の合計) × (1 + パラメータ上昇量減少の合計)  
- 計算したあと、小数点以下を切り上げる。  

### カードのパラメータ値(最終)
- カードのパラメータ値(最終) = カードのパラメータ値 + 切り上げ(集中 × N)  
  - N は「集中効果を1.5倍適用」のような指定がなければ 1  
  - 例: ハイタッチは N = 1.5  
  - 集中 × N は、好調・絶好調倍率をかける前に切り上げる。(レッスンで確認済み)  
    - 確認した例: 好調10ターン・絶好調4ターン・集中1でハイタッチ(無印)を使うと、パラメータ+48  
    - 切り上げ(1 × 1.5) = 2、(17 + 2) × (1.5 + 0.1 × 10) = 47.5 → 切り上げて 48  
    - 最後に1回だけ切り上げると (17 + 1.5) × 2.5 = 46.25 → 47 になり、合わない  

### 好調・絶好調倍率
| 好調 | 絶好調 | 倍率 |
|---|---|---|
| あり | あり | 1.5 + 0.1 × 好調のターン数 |
| あり | なし | 1.5 |
| なし | - | 1 |

- 絶好調は、好調がないと効果がない。  

## スコア
- 最終スコア上昇量 = 最終パラメータ上昇量 × スコアボーナス  
- 計算したあと、小数点以下を切り上げる。  

# バフのターン数
- 「Nターン」の効果は、ターン終了時に1減り、0になったら消える。  
- ターン数の指定がない効果は、消費されない限り試験の最後まで続く。  
- プレイヤーの操作中に付いた効果は、そのターンの終了時には減らない。  
  - 例: 自分のターンに好調1ターンを付けると、次のターンの終了時まで続く。  
- プレイヤーの操作前に付いた効果(ターン開始時に付く効果など)は、そのターンの終了時に1減る。  
- 「Nターン後」に予約された効果は、ターン開始時からカウントする。  
- すでに同じ効果がある場合、数値もターン数も今ある効果に足し合わせる。(要確認)  
  - 好調のターン数がどう合算されるかは、wikiの記述がわかりにくいのでゲームで確認する。
